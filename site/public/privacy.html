Privacy

This page covers plumbsearch.org. A Plumb node you run yourself keeps what you search on your own computer, and works the same way otherwise.

What the server keeps

  • There is no access log. The web server keeps no record of who visits or what they search for, and requests that fail (for example while the search node restarts) are not logged with your address or search either.
  • The search node logs no queries. Search history is off on this server.
  • There are no cookies for tracking, no analytics, and no ads. Pages load nothing from other servers: site icons are served by Plumb itself, and maps are drawn from coordinates rather than map tiles.
  • About you (/about) is optional. If you fill it in, your city, interests and site choices are kept in a cookie in your own browser, not on the server. Your browser sends that cookie with each search so results can fit you, and the server uses it for that search only. Clearing your cookies deletes it.
  • To stop one client from using up the server, the AI assistant endpoint (/mcp) and network search count requests per address. The counts are kept in memory only, never written to disk, and gone when the node restarts.

When your search leaves the server

  • Bangs. A search with !g, !ddg, !b or another bang is sent straight to that site (Google, DuckDuckGo, Bing and so on), which then sees it.
  • “Search the web with…” links. A node can show a link that hands your search to another search engine. It is off on this server; if you click one elsewhere, that engine sees your search.
  • Results you open. Clicking a result takes you to that site. The address you came from is not passed on, so the site doesn't see your search.
  • Network search. When this node searches the Plumb network, it never sends your words. It asks other nodes for a few numbered buckets of sites, padded with random ones, through another node that relays the request when there is one. The nodes that answer see the bucket numbers, and from those they could guess likely searches.
  • Private search (/private). Your search stays in your browser, which fetches buckets and ranks them itself. The server, or the other nodes it relays to, still see which buckets were asked for, so this is not a guarantee of anonymity.

What the server fetches by itself

  • Currency conversions use the European Central Bank's daily reference rates. The server downloads them itself, so the ECB never sees your search.
  • Weather answers use Open-Meteo's forecasts. The server asks for the town's coordinates, rounded to about a kilometre, and nothing else of your search; Open-Meteo never sees who asked.
  • The crawler fetches homepages, robots.txt, site icons and news feeds. None of it is tied to anyone's search.

More detail is in the network design and private search docs. Questions? Open an issue on GitHub.
